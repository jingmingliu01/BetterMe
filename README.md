## About This Repository

This repository is an early public MVP/demo version of the project. It was built to explore the core product idea: a Chrome extension that adds an AI-powered checkpoint before distracting websites, turning a user's purpose, time boundary, and exit plan into a concrete product outcome.

Later product development continued in a private repository and became Cocision. This public repo remains available as an archive of the early extension architecture, AI Check loop, local review workflow, and product-design process. It is not the current production codebase.

## From BetterMe to Cocision

BetterMe was the working name for the first MVP. Cocision is the current, more complete product that grew out of that work.

If you are evaluating the live product, use [cocision.app](https://cocision.app). If you are reviewing the engineering history, this repository can still be useful as a snapshot of the early public implementation.

## For Developers, Recruiters, and Reviewers

This repository may still be useful if you want to inspect an early implementation of:

- a Chrome MV3 extension product flow
- an AI checkpoint that converts model output into structured product state
- local-first storage and review tooling
- contract-driven AI output validation
- early prompt and evaluation workflow design

The current private product has moved beyond this public MVP, so do not treat this repository as the full source of truth for Cocision's current backend, account system, payment flow, deployment setup, roadmap, or production architecture.
